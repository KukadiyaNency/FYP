# Impact of Pandemic on Business Landscape  
📊 **Analysing the long-term effects of COVID-19 on various industries using ONS data.**  

## 🔹 Project Overview  
This project examines financial performance, workforce trends, trade variations, and business resilience during the pandemic.  

## 📁 Repository Structure  
- 📂 **Notebooks:** Jupyter Notebooks for **EDA, Hypothesis Testing, and Story telling and Visualisations**  
- 📂 **Data:** Raw datasets and Processed datasets  
- 📂 **Scripts:** Python scripts for **data cleaning & analysis**  
- 📂 **Figures:** Final **charts & visualisations**  

## 📊 Key Findings  
✔️ **Retail & Hospitality had the largest revenue loss** 📉  
✔️ **Furlough rates were highest in Hospitality** 🏨  
✔️ **Trade disruptions affected manufacturing the most** 🚢  
✔️ **Businesses using government support recovered faster** 📈  

## 🚀 Technologies Used

- **Jupyter Notebook / Google Colab**
